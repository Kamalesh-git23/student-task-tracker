# Student Task Tracker

## Description
A responsive task management application for students built using HTML, CSS, and Javascript.

## Features
- Add tasks
- Delete tasks
- Complete tasks
- Search tasks
- Local Storage Support
- Responsive UI

## Technologies
- HTML
- CSS
- Javascript
- Local Storage
- Git & GitHub
